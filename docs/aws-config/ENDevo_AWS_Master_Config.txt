ENVIRONMENT REPLICATION GUIDE
================================================================
To create DEV / TEST / UAT / STAGING — repeat these steps
with these naming changes:

Production prefix : endevo-*-production
Dev prefix        : endevo-*-dev
UAT prefix        : endevo-*-uat
Staging prefix    : endevo-*-staging

Services to duplicate per environment:
  - RDS instance (can use t3.micro for all non-prod)
  - Lambda function
  - API Gateway stage
  - Secrets Manager secret
  - S3 buckets (frontend + content)
  - CloudFront distribution

Services that can be SHARED across environments:
  - VPC and subnets
  - SES identity
  - Route53 hosted zone (use subdomains: dev.endevo.life)
  - WAF (add environment-specific rules)
  - SNS topic
  - CloudWatch log groups (separate by function name)

Cost per additional environment: ~$17/month (RDS dominates)
